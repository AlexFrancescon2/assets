# assets

3D models for a private Pokémon tabletop RPG companion app: battle-map props and terrain (the folders at the root) and the trainer characters (`trainer-models/`: bodies, haircuts, clothing, armour, weapons, animations).

**Not for reuse.** These files exist only to be served to that app. Please do not use, copy, hotlink or redistribute them.

This repository is written by a script in the app (`scripts/push-models.mjs`). Do not edit it by hand: changes made here are overwritten on the next push.
